# SE-SEP2026-Team-050

**Student Mentoring and Career Support Platform.** This is Option 2 of the IITM BS Software Engineering project for the September 2026 term.

The platform will connect current IITM BS students with alumni and recent graduates for career guidance. Students registered with IIC sign up and describe the problem they need help with. IIC then assigns each student a mentor from the platform's recommendations. The platform also covers tracking of mentoring activity and programme-level insights for administrators.
