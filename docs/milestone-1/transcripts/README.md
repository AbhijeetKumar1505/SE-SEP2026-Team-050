# Interview transcripts (anonymised)

Add one file per interview, named by participant ID: `S01.md`, `M01.md`, `A01.md`, and so on.

- **S** = student (primary user), **M** = alumnus/mentor (secondary user), **A** = programme administrator.
- Number participants in the order they were interviewed. Never reuse an ID.

## Before committing a transcript

- [ ] Names (participant's and anyone they mention) replaced with roles, for example "a senior from my batch"
- [ ] Employers, colleges, cities, phone numbers, emails and social handles removed or generalised, for example "a large IT services company"
- [ ] Consent recorded and noted at the top of the file
- [ ] Quotes left word-for-word; any interpretation is marked separately as `[Note: ...]`

## File header

```
Participant ID: S01
User group: Student
Date / mode / duration: 2026-10-17 / online / 22 min
Interviewer / note-taker:
Consent recorded: Yes (00:45)
Context: Degree level, working professional, considering MS
```

Raw recordings and unanonymised transcripts go in `raw/`, which git ignores. Keep the originals in the team's private drive.
